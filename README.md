# Telegram Animated Sticker and Emoji Converter

Convert videos, GIFs, and images into official Telegram-compliant animated `.webm` stickers and custom emoji.

All generated files adhere strictly to Telegram's [Encoding .WEBM with VP9 Guide](https://core.telegram.org/stickers/webm-vp9-encoding): VP9 codec, no audio, <= 3.0 seconds duration, <= 30 FPS, <= 256 KB file size, and exact dimensions (512px max edge for stickers, 100x100 for emoji).

---

## Prerequisites

- **Python 3.9+**
- **FFmpeg** (with `libvpx-vp9` enabled):
  - macOS: `brew install ffmpeg`
  - Ubuntu/Debian: `sudo apt update && sudo apt install -y ffmpeg`
  - Arch: `sudo pacman -S ffmpeg`

---

## Quick Start

### 1. Setup Environment

Using [`uv`](https://github.com/astral-sh/uv):

```bash
uv sync
source .venv/bin/activate
```

Or using standard `pip`:

```bash
pip install -e .
```

### 2. Convert Videos (One-Click)

Place your video or GIF files into `input_videos/` and run:

```bash
convert
# or
convert_video
```

Your stickers will be generated in `output_stickers/`.

## CLI Overview

### Single Video Conversion

```bash
# Convert to sticker (512px max edge)
tg-sticker convert input_videos/video.mp4 -o output_stickers/sticker.webm

# Convert to custom emoji (100x100)
tg-sticker convert input_videos/video.mp4 -o output_stickers/emoji.webm --mode emoji

# Trim snippet (start at 1.0s, duration 2.5s)
tg-sticker convert clip.mp4 -ss 1.0 -t 2.5

# Accelerate longer video to fit within 3.0 seconds
tg-sticker convert clip.mp4 --speed-to-fit

# Boomerang loop (ping-pong)
tg-sticker convert clip.mp4 --pingpong
```

### Batch Processing & Folder Watcher

```bash
# Convert all files from input_videos/ to output_stickers/
tg-sticker batch

# Live watcher: automatically converts files as they are added to input_videos/
tg-sticker batch --watch
```

### Compliance Verification

```bash
# Check if a .webm file satisfies all Telegram rules
tg-sticker check output_stickers/sticker.webm
```

### Browser Studio (Web UI)

```bash
# Start local web interface
tg-sticker web
```
Open `http://127.0.0.1:8080` in your browser for drag-and-drop conversion, interactive trimming, and live sticker loop previews.

## Uploading to Telegram

Upload stickers to Telegram through the official [@Stickers](https://t.me/Stickers) bot:

1. Open Telegram and message [@Stickers](https://t.me/Stickers).
2. Use `/newvideo` for animated stickers or `/newemojivideo` for custom emoji.
3. When prompted, send the generated `.webm` file as an **uncompressed Document / File** (do not send as photo/gallery video, or Telegram will re-encode it).
4. Send the associated emoji.
5. Publish the pack with `/publish`.

> Note: Vector stickers use `.TGS` files via `/newanimated`. Video stickers generated by this tool use `.WEBM` files via `/newvideo`.
